# Rewind default appearance

The owner selected the appearance already open in Chrome on 17 November 2026: **Smoked plastic**, case **#424847**, plain sticker **#ffdd80**. The inherited accent bands are **#98a573**, **#ffffff**, **#73a1de**. These settings are captured in `default.json` and offered as **Rewind yellow** in the presets.

Fresh visitors receive this preset. On the first release load, an exact match for the old automatically saved Archive orange default migrates once. Saved custom colours or other presets remain intact. The migration marker allows someone to intentionally select Archive orange again and keep it after reloading. Invalid or missing preset IDs fall back to Rewind yellow.

No cassette geometry, player behaviour, narration or script changes. Materials, controls, expanded menus and background continue to use the existing shared theme calculations.
